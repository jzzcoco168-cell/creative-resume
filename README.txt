你只需要改 index.html 和 images 文件夹。

1. 图片
把你的作品图片放进 images 文件夹，并使用下面这些文件名：
01-cctv.jpg
02-wechat.jpg
03-8300.jpg
04-campus.jpg
05-film-story.jpg
06-film-outline.jpg
07-f1.jpg

如果你想用 png/webp，也可以直接修改 index.html 里的 .jpg 文件名。

2. 作品链接
index.html 里每个作品都有 VIEW PROJECT / OPEN PROJECT。
现在点击会打开一个弹窗。
如果需要真正的链接，只需要在 script.js 里把对应的 "#" 改成真实网址。

3. 电影故事项目
已经独立成两个卡片：
05 = 电影故事项目设想
06 = 电影项目大纲

4. 字体
英文：Anton
中文：Noto Sans SC

5. 文件结构
index.html = 页面内容、项目文字、图片路径
style.css = 所有视觉设计
script.js = 只负责点击弹窗等交互
